Testing

The UCLA nf-test suite has integration cases for ProteinProphet, Fido, Epifany, and ProtLoom. All four use the same two E. coli mzML files and their route-specific metapipeline outputs. Set TEST_DATA_DIR in a local .env file using .env-template, then run a case inside a Slurm job:

bash test/run-nftest.sh test-integration-ProteinProphet

See test/README.md for the other case names and test-data layout. These tests require the lab's external metapipeline outputs; they are not self-contained fixtures. python -m unittest discover -s test -p "test_psm_features.py" checks both published feature formats with synthetic inputs.
